Writes the one line a gamer texts the boss to skip work on GTA 6 launch week: a dead badge reader, a security desk, and a manager who has to vouch for them. One line, 16 words, plain text, no setup, no signature — the joke is the excuse's own logic, since the boss it is texted to is the manager it needs.

## Run it

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt` (override with `MAKEFUN_OUTPUT`).
